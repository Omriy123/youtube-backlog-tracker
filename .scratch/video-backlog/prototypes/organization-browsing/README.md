# Organization/browsing interaction prototype

Throwaway, fictional, in-memory discussion artifact for [Specify remaining organization and browsing interaction edge cases](https://github.com/Omriy123/youtube-backlog-tracker/issues/25). Open `index.html` directly in a browser; no server, dependencies, account, API, or real Library data required. Reload/Reset restores fixtures.

Snapshot for continued grilling, 2026-10-18. Read the [consolidated decision handoff](https://github.com/Omriy123/youtube-backlog-tracker/blob/main/docs/design/library-organization-decisions.md) for the current accepted direction and open questions. This is an evidence archive, not approval of the complete organization slice. The following sections are chronological: later explicit corrections supersede earlier exploratory UI and behavior.

The page follows refined A. The current interaction uses main-area selection rows with From and In here / Elsewhere, no toolbar Selected jump button, Show only selected in the main results, the additional All / Matches panel switch, ordinary single-row drag, and Ctrl+drag of selected current results only. Arranging retains selection; filtered arranging is temporary. Guided scenarios also demonstrate deletion scopes, move tables, channels and stale actions. Q11 complete arrival order, exact defaults and the focused specification/workflow agreement remain open.

No durable persistence, real browser opening, production Undo/history, provider acquisition, capture/pending-review implementation, imports, scale guarantees, or theme decisions. No prototype code is promoted into production. `handoff-desktop.png` and `handoff-narrow.png` show this snapshot; historical screenshot/helper names mentioned below are local observation history and are not all included in the archive. Main keeps the decisions and source guide, not this simulator.

## Main selected-only filter and current-results Ctrl+drag clarification

The human clarified that filtered-selected means filtering the main list to selected rows. Retain the earlier selection-panel All / Matches feature as potentially useful. Added Show only selected in the main toolbar; it intersects current list/Library scope, search and channel filters while leaving selections elsewhere intact. The filter stays reachable at zero matches and clearing it restores saved order after temporary arranging. Matching-only removal includes this filter; whole-list deletion still includes all contents. Filter navigation/lifetime mechanics remain prototype defaults pending full-contract approval.

The human reported mixed-list Ctrl+drag failing, then clarified: **only move the ones on screen**. Ctrl+drag now carries selected videos in the current result set, independent of the selection panel's All / Matches choice. Hidden selections in other lists or behind filters stay selected and untouched. The result set is not limited by viewport clipping or scroll position. Explicit panel Move can still move All selected with its complete preview. This supersedes the previous panel-scope coupling for the Ctrl gesture.

A filtered example also leaves selected hidden same-list rows untouched while temporarily arranging selected matching rows.
