# Provider indicator comparison — accepted default and configurable alternatives

Open index.html directly in Chrome. This is a throwaway, fictional-data-only prototype with 20 videos: 15 YouTube, three Twitch and two websites. No real Library data, provider requests or extension writes are involved.

G is the accepted default: Thumbnails uses D's 6px provider edge plus metadata source on a neutral row; Compact uses a provider edge and tinted touching rows with thin separators. Defaults are vivid red for YouTube (#e62932), violet for Twitch (#8236e8), and neutral grey for websites (#737373).

Use the bottom arrows or Left/Right keys to compare B/D/E/F/G. The Thumbnails/Compact buttons change density. Palette comparison, tint strength, native provider color pickers and reset are interactive. URL parameters retain the demonstration choices; no persistent extension settings are implemented.

The user's final clarification requires production settings with full provider color pickers and independent edge/fill choices per density, including D edge-only, F tint-only, G's density-specific combination, or neutral styling. These configuration requirements are accepted; this prototype demonstrates the default and comparative styles, not their complete production settings interface.

The recorded original-title details remain unchanged. Synthetic thumbnail blocks are placeholders. Screenshot files show G's two densities. These assets establish presentation discussion only; they do not establish production behavior, provider acquisition, physical-device comfort, contrast compliance for arbitrary custom colors, or persistent preferences.

Accepted in the live user discussion on 2026-11-05: “yes, that's good for now” followed by “G is the default” and explicit customization requirements. Remaining Library feedback is tracked separately; this approval does not resolve all interaction or theme questions.
