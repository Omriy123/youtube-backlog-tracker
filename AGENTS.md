## Agent skills

### Issue tracker

Tasks live in GitHub Issues; durable specs live in `docs/specs/`. Read `docs/agents/issue-tracker.md` before creating, updating, or retiring tasks or specs. Use `.scratch/` for temporary local work only.

### Triage labels

Use the five default triage roles. Read `docs/agents/triage-labels.md` when assigning task status.

### Domain docs

Use a single-context layout. Read `docs/agents/domain.md` before exploring the codebase.

### Design and UI

Read `docs/agents/design.md` before design interviews or UI changes.

### Human testing

Read `docs/development.md#handoff-for-human-testing` whenever preparing a build for a human to test.
