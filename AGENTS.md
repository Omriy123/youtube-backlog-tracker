## Agent skills

### Issue tracker

Tasks live in GitHub Issues; durable specs live in `docs/specs/`. Read `docs/agents/issue-tracker.md` before creating or updating tasks or specs. Use `.scratch/` for temporary local work only.

### Triage labels

Use the five default triage roles. Read `docs/agents/triage-labels.md` when assigning task status.

### Domain docs

Use a single-context layout. Read `docs/agents/domain.md` before exploring the codebase.
