# Review standards

For visible UI changes, apply [rendered review and readiness](docs/agents/design.md#rendered-review-and-readiness): compare the rendered result with the relevant accepted reference and later human corrections. Evaluate layout and interaction fidelity alongside functional correctness.

Report missing-reference or missing-rendered evidence as a review gap. Keep judgments about visual hierarchy and usability distinct from automated test results and mechanical checks. Carry an evidence gap into PR readiness rather than converting a passing test count into a claim of complete UI fidelity.
