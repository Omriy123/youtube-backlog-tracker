# Reserve Inbox for deliberate placement decisions

Inbox represents videos awaiting a placement decision, so ordinary moves do not return already sorted videos to it. Undo may reverse an accidental departure, and deleting a custom list may send its videos to Inbox for reorganization. At Q44 the user deliberately broadened rediscovery: a generic repeat save of a watched/dismissed video explains its prior status and offers Dismiss or Keep, with Keep returning the existing record to Inbox. A destination shortcut instead keeps that record in the chosen destination with a review warning and a later Dismiss/Leave here prompt. This supersedes the earlier rule that repeat saves could never return videos to Inbox, while retaining one record per video and prior history.

The [expanded capture contract](../specs/expanded-capture.md) records the explicit 2026-10-17 refinement: saving stays simple, and generic rediscovery places the same record in Inbox immediately with pending review. Keep in Inbox confirms staying there; Dismiss removes active membership while preserving history. The destination-shortcut placement remains unchanged. This supersedes the earlier generic placement timing when expanded capture is delivered, not the single-record contract or the original first-slice approval.

The approved 2026-10-19 import contract explicitly adds a deliberate import-reconciliation exception: Inbox is offered like any other import destination. When a source reference identifies an active video already in another list, show its current destination and Leave there / Move here; Move here may explicitly choose Inbox. The human rejected preserving the ordinary-move prohibition inside this import table, saying it should be the same as any other list. This is a confirmed import decision, not an automatic repeat-save move or another membership. Ordinary organization moves and capture's active-duplicate default remain as specified in their contracts. Preserve First saved and First Inbox-exit; only an actual move changes Latest list-entry. The [approved import specification](../specs/backlog-import.md#binding-contracts-and-explicit-scope) records the full behavior and complete-contract approval.
