# Restrict returning videos to Inbox

Inbox normally represents videos awaiting their first sorting decision, so ordinary moves and rediscovery cannot return a previously sorted video to it. Repeat saves of watched videos instead prompt the user to queue the existing record directly into another list or ignore the addition, preserving prior history. Two explicit exceptions preserve recovery and reorganization: Undo may reverse an accidental departure, and deleting a custom list may send its videos to Inbox for a new placement decision.
