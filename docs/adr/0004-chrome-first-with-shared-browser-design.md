# Release on Chrome first while keeping browser adaptation straightforward

Q51 accepts an initial Chrome release on the condition that support for other desktop browsers stays simple to add. Use a shared WebExtensions product and UI, isolating browser-specific integration and packaging instead of spreading Chrome assumptions through Library behavior. This trades immediate simultaneous browser support for earlier Chrome validation while preserving a straightforward path to Edge and Firefox; exact compatibility and port effort require feature-level validation and browser tests. The [portability research](../research/browser-portability.md) identifies background execution, tab groups, and storage as boundaries to verify, rather than evidence that an untested package already supports another browser.
